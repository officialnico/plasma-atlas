What's happening
🌀
Low Shear (ŝ ≈ 0)
Field lines on neighboring surfaces twist at nearly the same rate. Perturbations stay aligned — shear doesn't tear them apart, so certain modes can persist.
ŝ → 0 : modes stay coherent
💥
High Shear (ŝ ≫ 1)
Neighboring field lines twist at very different rates. This "shearing" tears apart turbulent eddies — but can also couple to other drive mechanisms.
ŝ ≫ 1 : eddies get sheared
The key formula
ŝ = r / q · dq / dr
r = minor radius  ·  q = safety factor  ·  ŝ = magnetic shear
Physical Definition
ŝ = ρtor / q · dq / dρtor
In GENE's flux-tube coordinates, ŝ enters the parallel boundary condition
and the metric coefficients gxx, gxy, gyy.
Why GENE Cares
Parallel Boundary Condition
In a flux-tube simulation, GENE uses the "twist-and-shift" boundary condition: when a mode reaches the end of the parallel domain, it's shifted by Δkx = 2π ŝ ky. This connects the radial wavenumber spectrum across the domain — wrong shear means the wrong mode coupling.
Δk_x = 2π · ŝ · k_y
Metric Coefficients
The magnetic shear appears explicitly in GENE's field-aligned metric: gxx, gxy both depend on ŝ. These control the effective perpendicular wavenumber along the field line.
ITG / TEM Stability
Shear modifies the critical gradient for ITG modes. Typically, higher ŝ raises the critical gradient — but the relationship is nonlinear and interacts with elongation and triangularity.

Where does shear live?
SourceStatusDetails
EQDSK file
 NOT STORED Old format — only stores ψ(R,Z), p(ψ), q(ψ). No shear directly.
CHEASE solve
 COMPUTED Reconstructs equilibrium on Hermite elements, then differentiates q(ρ) to get ŝ with high accuracy.
GENE geometry file
 STORED Written by CHEASE interface in GENE's format. Contains ŝ, q, geometric coefficients along the field line.
GENE simulation
 USED Read once at initialization. Sets boundary conditions and metric for the entire run.
Common Pitfalls
⚠️
Numerical noise in dq/dr
If q(ρ) from EQDSK is noisy, the derivative blows up. CHEASE's Hermite reconstruction smooths this — don't compute ŝ from raw EQDSK data.
🔄
ρ definition mismatch
CHEASE and GENE can use different radial coordinates (ρ_tor vs ρ_pol). If the mapping is wrong, ŝ is wrong — and every k_x in the simulation is shifted.
